## Research tools

Experimental browser-based software for visual research.

- **SortBoard · Alpha.** Set up and replay visual sorting tasks with images, short videos and text cards. [Open SortBoard](https://dpfu.github.io/sortboard/) · [Source](https://github.com/dpfu/sortboard)
- **Folder Sort · Beta.** Compare images in a collection, sort them into nested folders and export the originals in that structure. [Open Folder Sort](https://dpfu.github.io/FolderSort/) · [Source](https://github.com/dpfu/FolderSort)
- **Video Board · Alpha.** Explore video on synchronised timelines. Arrange linked clips and stills and add codes and memos. [Open Video Board](https://dpfu.github.io/video-board/) · [Source](https://github.com/dpfu/video-board)
